# Code of Conduct

Lurk follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming and respectful, criticise ideas rather than people, and do not harass
anyone. This applies to issues, pull requests, discussions and every other project space.

## Reporting

If someone behaves in a way that breaks these rules, report it privately to the maintainers at
**[contact address – to be set before the repository goes public]**. Reports are kept
confidential.

The maintainers decide on consequences as the Contributor Covenant's enforcement guidelines
describe: from a private reminder to a permanent ban.
